# Checklist mobile manuelle — Les Fourrures Boréales

**Statut :** à exécuter sur **appareils réels** (iPhone + Android).  
**Ne pas cocher « réussi » sans essai physique.**

URL locale (même Wi‑Fi que le PC) : `http://<IP-du-PC>:8766/`  
Exemple : `http://192.168.x.x:8766/creations-personnalisees.html#mesure`

## Avant de commencer

- [ ] Serveur local démarré (`npx serve -l 8766`)
- [ ] Téléphone et PC sur le même réseau
- [ ] Pare-feu Windows autorise le port 8766 (si besoin)
