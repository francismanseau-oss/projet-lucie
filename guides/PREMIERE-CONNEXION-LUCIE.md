# Première connexion — Lucie (inventaire)

**Essai sur l’ordinateur seulement pour l’instant.**

1. Double-cliquer sur **Ajouter du stock (local)**  
   (dans le dossier *Fourrures Boreales - ESSAI LOCAL* sur le Bureau)
2. Taper le **mot de passe temporaire** que Francis vous a donné.
3. Choisir **votre** nouveau mot de passe (deux fois) → **Enregistrer mon mot de passe**.
4. Vous voyez la liste des produits.  
   Utilisez **+** ou **−**, ou tapez un chiffre puis **Enregistrer**.
5. Pour quitter : bouton **Quitter**.
6. Si vous oubliez votre mot de passe : **Mot de passe oublié ?**  
   (en local, Francis lit le lien dans un fichier du PC — plus tard ce sera un vrai courriel.)

Vous n’avez pas besoin de GitHub ni de Cursor.
